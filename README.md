# 관제 근무편성표 (Firebase 버전)

휴대폰과 PC에서 같은 주소로 접속해 근무 편성·대직·현황을 실시간으로 함께 보는 웹앱입니다.
데이터는 **Firebase Firestore**에 저장되고, 화면 파일은 **GitHub Pages**로 무료 배포합니다.
claude.ai 계정 없이 **이름과 비밀번호**로 로그인합니다.

| 구분 | 할 수 있는 일 |
|---|---|
| 슈퍼관리자 | 모든 화면 보기 + 편성·대직·인원·설정·계정 편집 |
| 관리자 (팀장·서무·행정팀) | 모든 관리 화면 보기 (편집은 불가) |
| 근무자 | 내 근무 캘린더, 편성표, 현황 보기 |

권한은 서버의 보안 규칙(`firestore.rules`)이 강제합니다. 화면을 조작해도 슈퍼관리자가 아니면 저장되지 않습니다.

---

## 1. Firebase 준비 (약 10분)

1. <https://console.firebase.google.com> 에서 **프로젝트 추가** (Google 애널리틱스는 꺼도 됩니다).
2. **Authentication → 시작하기 → 로그인 방법 → 이메일/비밀번호 → 사용 설정 → 저장**
3. **Firestore Database → 데이터베이스 만들기**
   - 위치: `asia-northeast3 (서울)` 권장
   - **프로덕션 모드**로 시작
4. Firestore의 **규칙** 탭을 열고, 이 폴더의 `firestore.rules` 내용을 전부 붙여 넣은 뒤 **게시**합니다.
5. **프로젝트 설정(톱니바퀴) → 내 앱 → 웹(</>) 앱 추가** → 앱 이름 입력 → 화면에 나오는 `firebaseConfig` 값을 `firebase-config.js`에 붙여 넣습니다.

## 2. GitHub Pages로 배포 (약 5분)

1. GitHub에서 **새 저장소**를 만듭니다 (예: `duty-roster`).
2. 이 폴더의 파일을 모두 올립니다. **`roster-data.json`은 올리지 마세요** (직원 이름이 들어 있습니다).
3. 저장소 **Settings → Pages → Branch: `main` / `(root)` → Save**
4. 1~2분 뒤 `https://아이디.github.io/duty-roster/` 주소가 생깁니다.
5. Firebase **Authentication → 설정 → 승인된 도메인**에 `아이디.github.io`를 추가합니다.

## 3. 처음 사용 설정

1. 배포된 주소를 열면 **처음 사용 설정** 화면이 나옵니다. 슈퍼관리자 이름과 비밀번호(6자 이상)를 정합니다.
   기존 명단의 슈퍼관리자와 **같은 이름**으로 만들면 가져오기 때 한 사람으로 합쳐집니다.
2. **설정 → 데이터 가져오기**에서 `roster-data.json`을 고르면 인원·경력·편성·설정이 옮겨집니다.
3. **설정 → 앱 계정**에서 공통 처음 비밀번호를 입력하고 **계정 만들기**를 누르면 계정 없는 인원 전원의 계정이 만들어집니다.
4. 주소와 처음 비밀번호를 단체 대화방에 공유하고, 각자 로그인 후 머리글의 **비밀번호**에서 바꾸게 합니다.

## 휴대폰에서 앱처럼 쓰기

- 아이폰(Safari): 공유 버튼 → **홈 화면에 추가**
- 안드로이드(Chrome): 메뉴 → **홈 화면에 추가** 또는 **앱 설치**

## 알아 두실 점

- **비밀번호를 잊은 경우**: Firebase 콘솔 **Authentication**에서 그 사용자를 삭제하고, Firestore의 `users` 컬렉션에서 같은 사람 문서를 지운 뒤, 앱의 인원·경력에서 계정을 다시 만듭니다.
- **이름을 바꾸면** 로그인 이름도 바뀌어야 하므로, 위와 같이 계정을 다시 만들어야 합니다.
- **명단 파일 업로드**: 엑셀(xlsx·xls·ods·csv), PDF, 한글(hwpx·hwp), ODT, 파워포인트(pptx), 사진(jpg·png)을 읽습니다. 표 첫 줄에 "이름, 팀" 같은 제목이 있으면 열 순서와 관계없이 읽습니다. 사진과 스캔 PDF는 브라우저에서 글자 인식(OCR)을 하므로 정확도가 떨어질 수 있으니, 등록 전 확인 칸에서 고쳐 주세요.
- **근무계획표 AI 읽기**(날짜별 근무자 자동 인식)는 claude.ai 버전에만 있습니다.
- 50~60명 규모는 Firebase 무료 요금제(Spark) 한도 안에서 충분히 운영됩니다.
- `firebase-config.js`의 값은 공개되어도 괜찮습니다. 데이터 보호는 보안 규칙이 맡습니다.
